# RotinaIESB - Organizador Acadêmico

Aplicativo desenvolvido para gerenciar compromissos diários do aluno no IESB.

## 1. Comandos de Inicialização

```bash
# Criação do projeto
npx create-expo-app@latest RotinaIESB --template blank

# Instalação das dependências obrigatórias
npx expo install @react-native-async-storage/async-storage react-native-safe-area-context

# Execução do projeto
npx expo start
