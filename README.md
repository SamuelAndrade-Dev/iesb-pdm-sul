# Aluno Online

Painel de gestão financeira feito para a rotina de estudantes, com controle de
orçamento mensal, gastos com alimentação, transporte, materiais e outras despesas.
O app usa React Navigation com abas e uma pilha de telas.

## Executar

Na raiz do projeto:

```bash
npm install
npx expo start
```

Use `i` para abrir no simulador iOS, `a` no emulador Android ou `w` no navegador.

Os lançamentos iniciais são dados de demonstração. Novas despesas ficam disponíveis
durante a sessão atual do aplicativo.
